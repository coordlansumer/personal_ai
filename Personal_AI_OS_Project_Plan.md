# Personal AI OS 项目规划文档

## 1. 项目目标

构建一个个人 AI Agent 系统：

-   可部署到手机、电脑、平板等终端
-   支持自然语言对话
-   具备长期记忆能力
-   可以调用工具完成任务
-   最终拥有家庭设备控制能力
-   支持与机器人、ROS2、IoT 系统融合

核心理念：

> 云端负责智能决策，本地负责现实世界执行。

# Phase 2：长期记忆系统

记忆分三层：

## 短期记忆

当前上下文。

技术：

-   Redis

## 长期语义记忆

保存：

-   兴趣
-   偏好
-   工作内容
-   习惯

技术：

-   Qdrant
-   Milvus
-   Chroma

## 结构化记忆

保存：

-   用户信息
-   家庭设备
-   任务记录

技术：

-   PostgreSQL

# Phase 3：Agent能力

从聊天机器人升级为任务执行系统。

流程：

    用户目标

    ↓

    Agent规划

    ↓

    调用Tool

    ↓

    执行

    ↓

    返回结果

例如：

用户：

"帮我准备明天会议"

Agent：

1.  查询日历
2.  查询文件
3.  总结资料
4.  创建提醒
